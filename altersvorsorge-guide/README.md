# Altersvorsorgedepot 教育指南

正式教育站（zh-CN）：准入 → 过程 → 选基金 → 退出提领，并嵌入计算器。

## 本地预览

```bash
cd altersvorsorge-guide
npm install
npm run dev
```

打开：http://127.0.0.1:5174/altersvorsorge-guide/

## 构建

```bash
npm run build
npm run preview
```

`base` 为 `/altersvorsorge-guide/`，便于日后与 GitHub Pages 同域部署。

## 计算器

嵌入：https://deutsch-alterversorge-rechner.apps.grok.bot  
同源应用源码见仓库 `alterversorge/`。
